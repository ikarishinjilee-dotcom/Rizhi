## 项目代码通读

通读了「日值」(rizhi) 项目的全部代码，建立了完整的架构认知。

### 项目概况
- npm workspace monorepo，包含 `apps/web`（Vue 3 + TS + Vite 主力 PC Web）和 `apps/uni-app`（uni-app 跨端客户端 + uniCloud 云函数）
- 版本 1.0.1，个人资产/记账/资金管理应用

### 核心架构
- **双数据源**：`VITE_DATA_SOURCE` 环境变量切换 IndexedDB（本地免登录）和 uniCloud（云端多用户）
- **分层**：Vue 页面 → Pinia appDataStore → Services（薄封装）→ Repositories（接口+双实现）→ Dexie/HTTP
- **云函数** `rizhi-api/index.js`：REST API，uni-id token 认证，11 个数据库集合，权限矩阵控制 admin/super_admin
- Web 测试基线：49 个单元测试 + Playwright E2E

### 关键文件位置
- 云函数 API：`apps/uni-app/uniCloud-alipay/cloudfunctions/rizhi-api/index.js`
- 本地数据操作核心：`apps/web/src/db/actions.ts`（~1700 行）
- 仓储选择枢纽：`apps/web/src/repositories/index.ts`
- 领域模型：`apps/web/src/domain/models.ts`
- 路由：`apps/web/src/app/router.ts`
